### 2) Retry never terminates on persistent failure (Code bug) ⚠️
- **Scenario / failing example:**
  ```ts
  await retry(() => Promise.reject(new Error('fail')), { retryCount: 3 })
  ```
- **Actual behavior:** The operation does not terminate — it keeps retrying and never propagates the rejected error (effectively an infinite retry/hang).
- **Root cause (code citation):**
  - File: `input.ts`  
  - Lines: 18–25
  - Code:
    ```ts
    let attempts = 0

    return fn().catch(async (err) => {
      if (attempts >= retryCount) {
        throw err
      }
      attempts++
      return retry(fn, { retryCount })
    })
    ```
  - Explanation: `attempts` is a local variable initialized to `0` on every call. Recursive calls create a fresh `attempts`, so the `attempts >= retryCount` condition never becomes true and retries never stop.
- **Fix (suggested):** Preserve `attempts` across retries (use a loop or pass attempts through recursion). Example safe implementation provided in corrected_readme.md.

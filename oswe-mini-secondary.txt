### 2) Implementation bug — attempts reset → infinite recursion
- **Failing example (snippet):**
  ```ts
  // a function that always rejects
  retry(() => Promise.reject(new Error('fail')), { retryCount: 3 })
  ```
- **Actual behavior / error:**
  - Execution keeps recursing until Node throws:
    - `RangeError: Maximum call stack size exceeded`
- **Root cause:** `attempts` is declared as a local variable in each `retry` invocation (reset to 0 each call). The termination check `attempts >= retryCount` can never become true across recursive calls, so recursion never stops on persistent failures.

Code citation (file + lines):
- input.ts lines ~17–25
  ```ts
  17: let attempts = 0
  19: return fn().catch(async (err) => {
  20:   if (attempts >= retryCount) {
  21:     throw err
  22:   }
  23:   attempts++
  24:   return retry(fn, { retryCount })
  25: })
  ```

Reproduction steps:
1. Import `retry` from input.ts.
2. Call `retry(() => Promise.reject(new Error('fail')), { retryCount: 3 })`.
3. Execution recurses until `RangeError: Maximum call stack size exceeded` is thrown.

Suggested code fixes:
- Convert logic to an iterative approach (loop) that preserves a single counter for attempts.
- Or add an `attempts` parameter to recursive calls so the counter is preserved.
